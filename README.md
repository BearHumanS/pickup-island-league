# Pickup Island League DB

Live database for the 24/7 YouTube broadcast [@PickupIsland247](https://www.youtube.com/@PickupIsland247/live): standings, team pages, every player's 35 ratings, leaders and league history.

- Site: `index.html` (built from `src.html` with `python3 build.py`)
- Data: `data/league-<lang>.json`, pushed by the broadcast machine after every round, plus `data/index.json`
